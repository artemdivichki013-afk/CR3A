# CR3A — vocal chain plug-in (VST3 for FL Studio)

Полноценный VST3-плагин на JUCE: вся вокальная цепочка в одном окне, 7 встроенных тем,
пресеты, живой анализатор спектра. Логотип (ушки) и название CR3A в шапке.

## Как получить готовый `CR3A.vst3` (Windows, без установки Visual Studio)

1. Создай пустой репозиторий на GitHub и загрузи в него **всё содержимое этой папки**
   (в том числе скрытую папку `.github`).
2. Открой вкладку **Actions** → workflow **Build CR3A**. Он запускается сам после загрузки
   (или нажми **Run workflow**). Сборка занимает 5–10 минут.
3. Когда появится зелёная галочка, открой запуск и скачай артефакт **CR3A-windows-vst3**.
4. Распакуй, запусти `install_windows.bat` (если Windows ругнётся на права, запусти от имени администратора).
   Он копирует `CR3A.vst3` в `C:\Program Files\Common Files\VST3`.
5. FL Studio: **Options → Manage plugins → Find installed plugins** (или *Verify plugins*).
   Плагин появится как **CR3A**. Добавляй его в слот микшера на дорожку вокала.

Чтобы сборка выкладывалась в Releases, поставь тег вида `v1.0.0`.

### Локальная сборка (по желанию)

```
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release --target CR3A_VST3
```
Результат: `build/CR3A_artefacts/Release/VST3/CR3A.vst3`. JUCE скачивается автоматически (версия 8.0.9).

## Цепочка обработки

`Input → Formant → EQ (+Harsh) → Compressor → Saturation → Distortion → Hyper → OTT → Doubler → Width → [Delay ‖ Reverb] → Mix → Limiter → Output`

| Модуль | Ручки | Что делает |
|---|---|---|
| **Formant** | FORMANT −12…+12 полутонов | Сдвигает форманты голоса, не меняя высоту ноты. Минус — голос глубже и «крупнее», плюс — светлее. Работает через спектральную огибающую (true-envelope по кепстру). |
| **Equalizer** | LOW END, LOW, MID, MID HIGH, MID END, AIR, HARSH | Полки и колокола под голос: 80 Гц, 220 Гц, 700 Гц, 2.2 кГц, 4 кГц, 12 кГц. **HARSH** — динамический подавитель резкости 3–9 кГц (режет только когда зона слишком громкая). Рядом живая кривая АЧХ. |
| **Compressor** | COMP, GAIN | Одной ручкой: COMP двигает порог и ратио вместе, мягкое колено, плавающий релиз, частичный авто-мейкап. GAIN — подгонка уровня. |
| **Saturation** | SAT, DIST, TONE | SAT — ленточная сатурация с пре/деэмфазисом. DIST — жёсткая асимметричная дисторшн с чистым басом, TONE — яркость дисторшна. Всё на 4× оверсемплинге (без алиасинга). |
| **OTT** | HYPER, OTT | OTT — 3-полосный вверх/вниз компрессор (кроссоверы 88 Гц и 2.5 кГц). HYPER — гармонический экситер верхов («блеск»). |
| **Doubler** | TYPE, MIX, WIDTH, DETUNE, PAN AUTO, TIME | Дублёр в духе Waves Doubler. TYPE: Dual (2 голоса L/R), Quad (4 голоса), Ping-Pong (3 отскока). DETUNE — плавающий питч копий, TIME — задержка копий, PAN AUTO — авто-панорама копий. |
| **Delay** | MIX, TIME, FEEDBACK, CUTOFF, MODE, DOTTED | Синхронно с темпом проекта: 1/32 … 1/1, режим «с точкой». MODE: Stereo / Ping-Pong / Tape (wow, flutter, насыщение). CUTOFF темнит повторы. |
| **Reverb** | MIX, DECAY, PRE-DLY, TONE | Стерео FDN-ревер (8 модулируемых линий), RT60 0.4–10 с. |
| **Width** | WIDTH 0–200 % | Сужение до моно и расширение: бас остаётся моно, к центру добавляется декоррелированный «бок», так что моно-вокал реально становится шире и всё равно безопасно сворачивается в моно. |

Внизу: **INPUT**, **OUTPUT**, **MIX** (сухой/мокрый), переключатели **LIMITER** (look-ahead, потолок −0.3 дБ), **MONO** (проверка моносовместимости), **BYPASS**.
Кнопка питания в заголовке каждого модуля включает/выключает его без щелчков.

Управление ручками: тяни мышью, двойной клик — сброс, колесо — точная подстройка.
Значение под курсором показывается над ручкой и на дисплее.

## Темы
Список справа вверху: **CR3A Graphite** (серый/чёрный/белый, по умолчанию), **FruityGear Aero**,
**Windows XP**, **macOS Liquid Glass**, **Windows 98**, **Terminal Green**, **Paper**.
Последняя выбранная тема запоминается и сохраняется в проекте. Окно можно тянуть за правый нижний угол — интерфейс масштабируется.

## Пресеты
Стрелки ◀ ▶ листают заводские пресеты, по клику на имя открывается меню: заводские, свои, **Save preset…**, **Load preset from file…**.
Пользовательские пресеты лежат в `Documents\CR3A\Presets` (`*.cr3a`). Пресеты не трогают INPUT/OUTPUT/MIX/LIMITER/BYPASS.

## Технические детали
* Латентность ≈ 44 мс при 48 кГц (в основном FFT формант-шифтера). Она постоянная, плагин сообщает её хосту, и FL Studio компенсирует её автоматически.
  Поэтому плагин предназначен для сведения; при записи вокала слушай себя напрямую через интерфейс, а не через плагин.
* Все параметры автоматизируются из FL Studio (правый клик на ручке → Create automation clip).
* Нагрузка: около 12 % одного ядра на 48 кГц при включённых всех модулях (Release, обычный ноутбучный CPU).
* Тесты звука лежат в `Tests/dsp_test.cpp` (сборка: `-DCR3A_BUILD_TESTS=ON`).

## Лицензия
Плагин построен на JUCE (AGPLv3 / коммерческая лицензия). Для личного пользования это не проблема;
если соберёшься распространять плагин публично, нужно либо открыть исходники под AGPL, либо купить лицензию JUCE.
